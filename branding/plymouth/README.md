# Plymouth theme

Skeleton theme using Plymouth's `script` module. Assets are generated by `scripts/build.py`.

The image definition copies this directory to `/usr/share/plymouth/themes/darkjuander` and runs `plymouth-set-default-theme darkjuander`. A missing file fails the image build. The initramfs is not rebuilt inside the container. `image/dracut/darkjuander-plymouth.conf` asks a later disk build to include the plymouth module. Not yet tested on a booted DARKJUANDER image, since none exists yet.

Files: `logo.png` (256 px), `wordmark.png`, `progress_box.png` / `progress_bar.png` (240x4), `entry.png` (passphrase field), `bullet.png`, `lock.png`, plus `.svg` sources.
