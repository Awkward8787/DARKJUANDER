# DARKJUANDER branding

Brand identity kit for DARKJUANDER. Start with [brand-guide.md](brand-guide.md). Usage terms are in [LICENSE-BRAND.md](LICENSE-BRAND.md); these files are not under the code's Apache-2.0 license.

Recommended logo, and the default everywhere in this repository: **Umbra Eclipse** (`logo/eclipse/`, direction A). `BUILD_DIRECTION` is `eclipse`. `python3 scripts/build.py` writes `logo/logo-directions.png`, the side-by-side of the four directions. That sheet is not committed.

## Rebuild

Needs Python 3, `fonttools`, `Pillow`, and `rsvg-convert` (librsvg). `grub2-mkfont` is optional.

```
pip install fonttools pillow
python3 scripts/build.py                       # all logo directions, OS assets, social preview
python3 scripts/build.py --only social         # GitHub social SVG and PNG
python3 scripts/build.py --only os             # eclipse OS assets and the social preview
python3 scripts/build.py --direction lattice   # OS assets in another direction (eclipse, tag, lattice, route)
python3 scripts/build.py --no-png              # SVG only, including the social SVG
python3 scripts/contrast.py                    # rewrites research/contrast.md
```

`rsvg-convert` is required for any command that writes PNGs. Change a color in `src/palette.json`, rerun `build.py` and `contrast.py`, and the assets and the contrast table update. CI runs `build.py --only social` and fails if the committed social PNG or SVG differs.

## In this repository

This folder is `branding/` at the root of `Awkward8787/DARKJUANDER`. The image build generates the Plymouth theme, wallpapers, and hicolor icon from these sources and installs them. GRUB art is not installed. That image has been built in CI and has not been booted. See [../docs/BASE.md](../docs/BASE.md).

`social/darkjuander-social-1280x640.png` is the image to upload under GitHub Settings > Social preview. `scripts/build.py` renders it from `social/darkjuander-social-1280x640.svg`. It is the horizontal Umbra Eclipse logo and the tagline "Agents inside a boundary you can audit." on `#0A0C11`.
